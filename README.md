# Thank You, Sir 😊

A small interactive thank-you page.

## Files
- index.html – the page structure and text
- style.css – colours, layout and animations
- script.js – page navigation, slider, cards and confetti

## Publish on GitHub Pages
1. Create a new repository on GitHub (for example `thank-you-sir`).
2. Upload all four files to the root of the repository.
3. Go to Settings > Pages.
4. Under "Build and deployment", choose Source: Deploy from a branch, Branch: main, Folder: / (root), then Save.
5. After a minute, your link will be https://YOUR-USERNAME.github.io/thank-you-sir/

## Personalize
- Replace "Sir" with his name in index.html and script.js.
- Edit the journey lines in script.js (the `stages` list).
- Edit the four card messages in index.html.
